**Tag legend:** *Subject* is the broad field; *Tags* flag the language or tool (`Python`, `SQL`), the level (`Beginner`), and the focus (`Data Structures`, `Databases`). `Outcomes-mapped` means I've mapped every course objective to one or more recognized frameworks (for computer science: ABET CAC student outcomes and the ACM/IEEE-CS CS2023 curriculum guidelines). It's my own alignment, not an accreditation or an official endorsement; each course page names the frameworks it uses and links the full map. A planned course gets the tag once its map exists. If a course also aligns with a specific university's course objectives, its course page says so in a footnote; courses aren't tagged by university. *Status* is ✅ Complete, 🟢 In progress, or ⚪ Planned.

You read and learn here on the site. When a course includes code to run, each page links its starter files for direct download, and the whole course is in an open repository too; see [Using GitHub](../guides/using-github.md) if that's new to you.
