# Start Here

<!-- author_status: dakota-authored | section: full page (edited and approved by Dakota 2026-11-05) -->

New to programming? You're in the right place. Here's the path.

Already in a university CS program and it's just not clicking the way it's being presented? You're in the right place, too; sometimes a different phrasing or example is all it takes for that "light bulb" 💡 moment.

## 1. Set up Python (once)

Before anything else, get Python working on your computer. The [Install Python guide](guides/install-python.md) walks you through it on macOS, Windows, or Linux; no experience needed, could take around 15–20 minutes.

## 2. Pick a course

Head to the [course catalog](courses/index.md). If you've never programmed, start with **Computer Science 1**. It assumes zero background and builds up from "what is a computer program?"

## 3. Learn by doing

Every unit has small, low-stakes exercises *before* any graded work, so you can check your understanding without pressure. Type the code yourself, don't just read it. That's where the learning happens.

## 4. Get unstuck the right way

When something breaks (it will! that's normal), gather [a few details](guides/terminal-basics.md#getting-your-details): your operating system and shell, your Python version, the exact command you ran, and the exact error text. Those are what let anyone help you fast. Using an AI tutor to *explain* an error is fair game; using it to write code you can't explain is not.
