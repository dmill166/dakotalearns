*[IDLE]: Integrated Development and Learning Environment: Python's built-in editor and shell.
*[IDE]: Integrated Development Environment: an editor bundled with tools to write, run, and debug code.
*[REPL]: Read-Eval-Print Loop: an interactive prompt that runs code one line at a time (e.g. Python's >>> shell). Not to be confused with Replit, an online IDE.
*[PATH]: An operating-system list of folders to search for programs, so you can run them by name in a terminal.
*[CLI]: Command-Line Interface: typing commands in a terminal instead of clicking.
*[OS]: Operating system: the software that runs your computer (Windows, macOS, Linux).
*[I/O]: Input/Output: data going into a program and coming back out.
*[OOP]: Object-Oriented Programming: bundling data and its behavior into objects.
*[ABET]: The U.S. accreditor for college engineering and computing programs.
*[CAC]: Computing Accreditation Commission: the ABET commission that covers computing programs.
*[ACM]: Association for Computing Machinery: the main professional society for computing.
*[IEEE-CS]: IEEE Computer Society: co-author, with the ACM, of the standard computing curricula.
*[CS2023]: The ACM/IEEE-CS 2023 curricular guidelines for computer science degrees.
*[OCW]: MIT OpenCourseWare: MIT's free, openly licensed course materials.
*[venv]: Virtual environment: an isolated, per-project set of Python packages.
